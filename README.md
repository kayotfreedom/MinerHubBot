# Telegram-бот «MineHub» (Игровая экономика и Авто-бур)

Игровой Telegram-бот на базе aiogram (v3), представляющий собой симулятор шахтерского дела. Пользователи могут добывать ресурсы, прокачивать уровни, покупать улучшения, открывать кейсы и запускать «Авто-бур» для пассивного заработка. Включает в себя развитую систему внутриигровой валюты и админ-панель.

## 🎮 Основной функционал

### Для игроков (Игровая механика):
- Добыча ресурсов: Система «копания» с задержкой (кулдауном). Игроки могут выбирать тип руды (Земля, Камень, Железо) и использовать кирки разного уровня для увеличения добычи.
- Инвентарь и продажа: Просмотр добытых ресурсов и их продажа за внутриигровую валюту (хаб-коины).
- Магазин: Покупка более мощных инструментов (каменная, железная, алмазная, золотая кирка).
- Прокачка уровня: Улучшение уровня аккаунта за счет добытой руды и накопленных денег.
- Кейсы: Система открытия кейсов разных редкостей (Обычный, Редкий, Мифический, Экипировка, Улучшения, Предметный).
- Авто-бур: Покупка и использование автоматического бура. Игроку необходимо добывать топливо, улучшать бак и запускать механизм для пассивного получения руды в инвентарь бура.
- Реферальная система: Приглашение друзей за внутриигровую валюту.
- Донат и промокоды: Пополнение баланса и активация промокодов на получение бонусов.

### Для администраторов:
- Панель управления: Доступ по команде /admin.
- Управление валютой: Ручное начисление и списание донат-валюты пользователям по ID.
- Рассылки: Отправка сообщений всем пользователям или тем, кто не привел ни одного реферала.
- Управление каналами: Добавление/удаление каналов для обязательной подписки.
- Управление промокодами: Создание и деактивация промокодов.

## 🛠️ Установка и запуск

### 1. Установка зависимостей
Убедитесь, что у вас установлен Python 3.10 или выше.

pip install aiogram telethon

(Библиотека telethon требуется, так как в коде бота импортируется TelegramClient).

### 2. Настройка settings.py
Откройте файл settings.py и укажите свои данные:

- TOKEN — токен бота (от @BotFather).
- channel_ids — список ID каналов для обязательной подписки.
- admins — список ID администраторов.

### 3. Запуск
При первом запуске автоматически создадутся все три базы данных (database.db, auto_bur.db, casedatabase.db) и необходимые таблицы. Запустите бота командой:

python bot.py

## ⚠️ Важные технические замечания и Known Issues

В текущей версии кода присутствуют некоторые особенности, которые стоит учесть перед запуском в продакшн:

1. Смешение версий aiogram: В конце файла bot.py находятся строки from handlers.ignore_blocked import ... и executor.start_polling(...). Это синтаксис из aiogram 2.x. В aiogram 3.x они не работают, и их следует удалить, так как код уже запускается через asyncio.run(main()).
2. Незавершенные функции: Механика «Авто-бура» (start_bur_function) содержит бесконечный цикл while с time.sleep(1). Это блокирует асинхронный поток (event loop) и заставит бота «зависнуть» для всех остальных пользователей. Для корректной работы пассивной добычи необходимо использовать asyncio.sleep() и выносить логику в фоновые задачи (например, через asyncio.create_task).
3. Опечатки в названиях таблиц: В файле casedatabase.py функция add_case_user обращается к таблице database.db и пытается обновить столбец update_case вместо uluch_case. Это приведет к ошибке при попытке выдать кейсы новому пользователю.
4. Безопасность: Токен, указанный в файле, скомпрометирован (находится в открытом виде в тексте). Для реальной работы сгенерируйте новый токен в BotFather и используйте .env файл.
